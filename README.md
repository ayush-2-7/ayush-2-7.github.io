# ayush-2-7.github.io

My portfolio site. Plain HTML/CSS/JS, hosted on GitHub Pages.

**To update:** edit `data.js` (all content lives there), then:

    git add -A && git commit -m "Update portfolio" && git push

It goes live at https://ayush-2-7.github.io in about a minute. To preview locally, run `python3 -m http.server` and open http://localhost:8000.
